# Faheem Chat Android App

This Android Studio project wraps the deployed Faheem Innovations Chat web app in a secure WebView.

## Build

1. Install Android Studio and Android SDK 35.
2. Open this `android` directory in Android Studio.
3. Let Gradle sync, then run `app` on a device/emulator.
4. Use **Build > Build Bundle(s) / APK(s)** to create an APK or AAB.

The app URL is configured in `app/src/main/res/values/strings.xml`.
